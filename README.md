📌 About the Project

Al-Mutairi Fiber Glass is a modern frontend web project focused on creating a strong digital presence for a fiber glass business.

The website provides visitors with an easy way to explore:

- Company information
- Fiber glass products
- Services and solutions
- Completed projects
- Product galleries
- Promotional videos
- Visual showcases
- Contact and business information

The interface is designed to be responsive, professional, and optimized for a smooth browsing experience across desktop, tablet, and mobile devices.

🚀 Getting Started

1. Clone the Repository

git clone https://github.com/sa23515193-hash/Al-Matiri-Fiber-Glass.git

2. Navigate to the Project

cd Al-Matiri-Fiber-Glass

3. Install Dependencies

npm install

4. Start the Development Server

npm run dev

The project will run locally through the Vite development server.

---

📦 Production Build

To create an optimized production build:

npm run build

The generated production files will be available inside the:

dist/

directory.

---

🌍 Deployment

The project is configured for deployment through GitHub Pages.

The Vite base path is configured for:

/Al-Matiri-Fiber-Glass/

Production deployment can be generated using:

npm run build
npx gh-pages -d dist
